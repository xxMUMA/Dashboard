# Day 1 — Foundation

## Goal

Plan the dashboard and build the first version of its interface.

## Completed

- Set up the Next.js and TypeScript project.
- Built the dashboard layout, search input, date selector, result cards, and engagement summary.
- Added a light and dark mode toggle.
- Added a simple page describing the services planned for the dashboard.
- Included clearly labeled fictional posts so the interface can be explored before live search is connected.

## Problem I faced

## Run this version

From the repository root, run `npm install` and then `npm run dev`. Open `http://localhost:3000`. No API key is needed for the Day 1 sample interface.
