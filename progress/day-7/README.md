## What I built

Over seven days, I built an open-source social listening dashboard to search public posts, save results, analyse sentiment, and explore how conversations change over time.

The final walkthrough brings together live search, platform grouping, selectable result limits, saved searches, AI sentiment labels, conversation insights, and trend charts from saved checks. This remains a local prototype; the challenge is complete, and development will continue.

## What I learned

I started as a beginner with an idea and learned to break it into smaller, manageable tasks. Building one part at a time helped me keep moving when something did not work.

Connecting an API is only the beginning. Error handling, private credentials, and understandable results are part of making a useful dashboard. More controls do not always improve the experience; simplifying the interface can make it easier to use.

AI sentiment labels need context. I still need to read the original posts and review the model's conclusions. Trend charts also need careful interpretation: saved searches capture samples, and changing a result limit can change the chart without proving that the wider conversation changed.

Codex helped me implement the project, but I still had to test the features, notice problems, and explain what needed to change. I learned to ask clearer questions and check whether each feature solved the intended problem.
